# Как опубликовать Gym Tracker и поставить его на iPhone

Нужны: компьютер с Windows, браузер, бесплатный аккаунт на github.com и iPhone с Safari. Ничего устанавливать на компьютер не нужно.

## Часть 1. Публикация на GitHub Pages

1. Распакуйте ZIP-архив в любую папку. Внутри должны лежать `index.html`, `sw.js`, `styles.css`, папки `js` и `icons` и другие файлы.
2. Зайдите на github.com и войдите в аккаунт (или создайте его).
3. Нажмите **+ → New repository**. Название, например, `gym-tracker`. Выберите **Public**. Нажмите **Create repository**.
4. На странице нового репозитория нажмите ссылку **uploading an existing file**.
5. Откройте папку с распакованными файлами, выделите ВСЁ содержимое (Ctrl+A) и перетащите в окно браузера. Важно перетаскивать содержимое, а не саму папку `gym-tracker`, чтобы `index.html` оказался в корне репозитория.
6. Дождитесь загрузки всех файлов (папки `js/views` и `icons` тоже должны появиться), внизу нажмите **Commit changes**.
7. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите Source: **Deploy from a branch**, Branch: **main**, папка **/(root)**, нажмите **Save**.
8. Подождите 1–3 минуты и обновите страницу. Вверху появится адрес вида `https://ВАШ-ЛОГИН.github.io/gym-tracker/`. Откройте его на компьютере: должно появиться приложение.

## Часть 2. Установка на iPhone

1. Откройте этот адрес в **Safari** на iPhone.
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Прокрутите меню и выберите **«На экран «Домой»»**, затем **«Добавить»**.
4. Запускайте приложение **только с иконки на главном экране**.

> **Важно про данные.** Safari и приложение с главного экрана хранят данные отдельно. То, что вы ввели во вкладке Safari, в установленном приложении не появится. Поэтому после установки пользуйтесь только иконкой. Если уже что-то вводили в Safari, сделайте там копию («Данные → Сохранить копию») и загрузите её в установленное приложение.

## Часть 3. Проверка офлайн-режима

1. Откройте приложение с иконки один раз при включённом интернете и подождите несколько секунд.
2. Включите авиарежим и снова откройте приложение. Оно должно работать, а новые тренировки сохраняться.

## Резервные копии (обязательно)

Данные лежат только в памяти этого iPhone. Если удалить иконку приложения, сбросить данные Safari или потерять телефон, данные пропадут. Синхронизации между устройствами нет.

- Раздел **Данные → Сохранить копию** создаёт файл JSON. Сохраните его в «Файлы» (iCloud Drive) или отправьте себе.
- Делайте копию хотя бы раз в 2 недели. Приложение само напомнит на главном экране.
- Восстановление: **Данные → Выбрать файл…**.

## Как обновить приложение позже

1. Замените изменённые файлы в репозитории на GitHub (Add file → Upload files, с тем же именем).
2. В файле `sw.js` увеличьте номер: `gym-tracker-v1` → `gym-tracker-v2`.
3. На iPhone откройте приложение с интернетом, закройте его (смахните вверх) и откройте ещё раз: новая версия подхватится.

Не переименовывайте репозиторий и не меняйте логин после установки: адрес изменится, и приложение откроется с пустой базой. В таком случае восстановите данные из копии.

## Проверка на компьютере (по желанию)

Файл `index.html` нельзя просто открыть двойным щелчком (модули и офлайн-режим требуют сервера). Откройте папку в командной строке и выполните `python -m http.server 8000`, затем перейдите на `http://localhost:8000`.
