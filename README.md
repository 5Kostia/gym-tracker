# Gym Tracker

Личное PWA для записи тренировок и замеров тела на iPhone. Чистые HTML, CSS и JavaScript (ES-модули), без сборки и без внешних библиотек. Данные хранятся в IndexedDB на устройстве. Хостинг: GitHub Pages.

Разделы: Главная (календарь, сводка), Тренировки (история и редактор), Замеры, Прогресс (рекорды и графики), Данные (экспорт и импорт JSON).

Не делает: синхронизацию между устройствами, облако, аккаунты. Это PWA, а не приложение из App Store.

Установка и публикация: см. `ИНСТРУКЦИЯ.md`. Устройство кода: `ARCHITECTURE.md`. Состояние: `PROJECT_STATUS.md`, `TODO.md`, `CHANGELOG.md`.
