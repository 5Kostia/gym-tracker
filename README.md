# Gym Tracker

Дневник тренировок и замеров для телефона и компьютера. Приложение публикуется на GitHub Pages как статический сайт. Клиентский Firebase SDK версии 12.10.0 входит в комплект, сборка для публикации не требуется.

## Аккаунт и первое сохранение

1. В проекте Firebase включите вход через Google. В Authentication → Settings → Authorized domains укажите домен сайта.
2. В Firestore → Rules опубликуйте содержимое файла `firestore.rules`. Эти правила разрешают каждому участнику читать и менять записи своего дневника.
3. В базе `(default)` создайте коллекцию `allowedUsers`. Для каждого участника создайте документ с его адресом Google в качестве ID и полем `enabled` типа boolean со значением `true`. Чтобы отозвать облачный доступ, установите `false`.
4. Разместите файлы в прежней папке GitHub Pages. После публикации откройте приложение по прежнему адресу с интернетом. Если открыта предыдущая версия, закройте и снова откройте приложение.
5. На устройстве со старыми записями откройте «Аккаунт», войдите через Google и нажмите «Перенести записи с устройства». Проверьте адрес в подтверждении. После статуса «Сохранено в облаке» откройте тот же аккаунт на втором устройстве.

Гостевой дневник хранится в браузере до переноса. Перенос одной транзакцией помещает записи в локальное хранилище выбранного аккаунта и ставит их в очередь отправки. В аккаунте приложение сохраняет изменения автоматически, в том числе удаления. После офлайн-тренировки откройте дневник с интернетом для завершения отправки. При одновременном редактировании одной записи сохраняется версия с более поздней отметкой изменения. Копию JSON по-прежнему можно выгрузить или импортировать во вкладке «Аккаунт».

При обновлении с v18 сначала опубликуйте файлы приложения и откройте новую версию, затем опубликуйте новые правила в Firebase → Firestore → Rules. Загрузка файла правил в GitHub сама по себе правила базы не обновляет. Правила проверяют поля и типы документа, а приложение проверяет содержимое JSON. Повреждённая запись пропускается, а во вкладке «Аккаунт» появляется сообщение о ней. При удалении клиент сохраняет отметку об удалении, которую получают остальные устройства.
